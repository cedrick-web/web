# DevSprint V1 Revision Checklist

## Module 1

- [ ] I can identify input, process, and output.
- [ ] I can decompose a problem.
- [ ] I can write pseudocode before code.
- [ ] I can identify edge cases.

## Module 2

- [ ] I can choose arrays, objects, Map, or Set deliberately.
- [ ] I understand mutation and early returns.
- [ ] I can write tests for common cases.

## Module 3

- [ ] I can use traversal, frequency patterns, two pointers, and sliding-window reasoning.
- [ ] I can explain palindrome and anagram approaches.
- [ ] I can merge or transform arrays safely.

## Module 4

- [ ] I can perform linear search.
- [ ] I know the precondition for binary search.
- [ ] I can reason about search boundaries.

## Module 5

- [ ] I understand numeric JavaScript sorting.
- [ ] I can explain selection, insertion, merge, and quick-sort mechanics.
- [ ] I can choose a comparator with explicit tie-breaking.

## Module 6

- [ ] I understand stack and queue behavior.
- [ ] I can implement linked-list traversal.
- [ ] I can use Set and Map appropriately.
- [ ] I understand basic binary-search-tree insertion and traversal.

## Module 7

- [ ] I can recognize O(1), O(log n), O(n), O(n log n), and O(n²).
- [ ] I can identify dominant work in nested code.
- [ ] I can explain time/space trade-offs.

## Module 8

- [ ] I can combine multiple techniques in one problem.
- [ ] I can state assumptions and business rules.
- [ ] I can test boundary conditions.
- [ ] I can explain the final solution clearly.

## Final Project

- [ ] I completed Student Performance Analyzer without copying the reference implementation.
- [ ] I wrote tests.
- [ ] I can explain every major function.
- [ ] I can state the complexity of the main operations.
- [ ] I can identify at least one possible improvement.

## Final mastery check

For three random challenges, start from a blank file and complete the full DevSprint loop without opening the solution until the end.
