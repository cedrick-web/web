## Start here

This toolkit is designed to make you solve problems, not merely read about them.

Use this loop for every challenge:

**Understand → Identify Input/Output → Break Down → Choose Technique → Algorithm → Pseudocode → Code → Test → Debug → Analyze Complexity → Improve**

Do not immediately open the reference solution. The uncomfortable part where you try to solve the problem is where the learning happens. Humanity unfortunately cannot download understanding like an app update.

## How to use each challenge

### Step 1: Understand
Read the problem twice. Identify exactly what is being requested.

### Step 2: Define input and output
Write down:

- What comes in?
- What must come out?
- What constraints matter?

### Step 3: Attempt
Try your own approach before reading the hints.

### Step 4: Use hints progressively
Use the smallest hint that helps you move forward.

### Step 5: Write pseudocode
Describe the algorithm in plain structured steps before writing JavaScript.

### Step 6: Implement
Turn the pseudocode into readable JavaScript.

### Step 7: Test
Test normal cases and edge cases.

### Step 8: Debug
When a test fails, reproduce the failure, isolate the cause, fix it, and retest.

### Step 9: Analyze
Record time and space complexity.

### Step 10: Extend
Attempt the extension challenge without immediately looking at the reference answer.

The Final Project is the **Student Performance Analyzer**.

Build it yourself before comparing your implementation with the reference approach. The project combines statistics, searching, sorting, ranking, pass/fail rules, attendance analysis, testing, and complexity reasoning.
